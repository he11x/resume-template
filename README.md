# 个人简历 HTML 模板

一个简洁、响应式的个人简历 HTML 模板，单个文件即可预览和打印，无需安装任何依赖。

## 快速使用

1. 下载 `个人简历_html模板.html`
2. 用浏览器打开，即可预览简历效果
3. 使用文本编辑器修改文件中的个人信息
4. 浏览器中 `Ctrl+P` 打印为 PDF

## 模板包含

- 左侧栏：照片、基本信息（电话、邮箱、性别、年龄、实习期等）
- 右侧内容：教育经历、实习经历、项目经历、个人技能

## 样式特点

- 单文件零依赖，HTML + CSS 内联
- 左右分栏布局，打印友好
- 最宽 1000px，适合 A4 纸张输出

## 自定义

用任意文本编辑器打开 HTML 文件，搜索 `____` 或占位文字（如"姓名"、"学校名称"）进行替换即可。
